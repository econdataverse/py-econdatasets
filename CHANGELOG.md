# Changelog

## 0.1.0 (unreleased)

- Initial release mirroring the R package [econdatasets](https://github.com/econdataverse/r-econdatasets):
  - `ed_get()` downloads a table of an EconDataverse dataset as a Polars DataFrame.
  - `ed_get_tables()` lists the Parquet tables of a dataset.
  - `ed_get_datasets()` lists all datasets of the EconDataverse organization on Hugging Face.
- Documentation website built with Great Docs.
